## Frozen benchmark

The V6 benchmark is a frozen 12-case wrapper over the exact successor-v2
synthetic source corpus. It covers:

- unique cash and unique printed metrics;
- multiple compatible meanings, no Registry type and missing discriminator;
- repeated headers and unsupported sources;
- detail versus subtotal, adjacent equal and adjacent FX values;
- optional missing dimensions and forbidden neighbours.

Repeated headers and unsupported sources terminate in code-owned technical
preclose. The remaining ten cases enter the V6 semantic pipeline. Adjacent
equal evidence must expose zero Typed Options.

## Local proof

`Gate2FinancialSemanticV6LocalProofFactory.create` is the only zero-call local
proof entrypoint. For semantic cases it uses the production factories for
Evidence Bundle, Candidate Compilation, packet, minimal choice contract,
deterministic expansion and total materialization. Both provider-visible
choices are exercised.

All twelve canonical artifacts then pass Financial Context projection,
Financial Domain catalog construction, in-memory persistence round trip and
query proof.

The proof checks exact source membership, unclassified retention, duplicate
and cross-scope refs, terminal ownership, artifact validation, catalog/query
coverage and negative fail-closed cases.

## Safety

Fixture choices are local oracle inputs, not provider outputs. The proof makes
zero provider calls, performs no fallback, repair or retry, writes no
persistence, activates no runtime route and contains no customer data.
