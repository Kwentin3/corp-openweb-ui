## Вывод

Короткий общий контекст не ухудшил старшие модели и устранил основной сбой слабой модели: для простого нового файла модель сразу вызывает соответствующий create tool, не загружая общий skill/help. Help остаётся доступен точечно для существующего сложного документа либо новой таблицы, диаграммы или картинки.

Известный остаточный UX-дефект: отдельные Gemini-модели после уже корректного вложения иногда оставляют пустой финальный текст или показывают сырой JSON. Это не признано ошибкой созданного файла и не закрыто ослаблением проверки результата.
