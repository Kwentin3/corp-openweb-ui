# Сводка Office Tools перенесена в общий отчёт для акта

Актуальная единая точка входа — [сводный отчёт для акта](README.md).
Он включает офисные инструменты, их последующие доработки, отдельную доработку
транскрибации и диагностику. Для выбора части состава используются коды работ.

Этот файл оставлен для совместимости существующих ссылок и не ведёт
самостоятельный расчёт часов.

[Прежняя сводка только Office Tools и диагностики](https://github.com/Kwentin3/corp-openweb-ui/blob/939914d792a3fbabe0a3f539458b9744e4efdccd/docs/commercial/OFFICE_TOOLS_COMPLETED_WORK_SUMMARY.md)
сохранена в истории. Её состав не включал доработку транскрибации.
